VoteTorrent News and Updates

Stay informed about the latest developments in the VoteTorrent project.

Hardware-Backed Device Verification

July 27, 2026

Registration can now carry cryptographic proof that it came from a genuine, unmodified phone. The Voter app generates a signing key inside the device's own secure hardware, and the Authority app verifies both that key and the device behind it — entirely offline, with no call home to any server. This is a direct defense against someone scripting thousands of fake registrations. The mechanism is built and integrated; it will be switched on as elections move toward real use.

The Voter App Takes Shape

July 23, 2026

VoteTorrent now has two apps: the Authority app for the officials who run an election, and the new Voter app for everyone else. The Voter app covers registration, ballots, and QR scanning, and it now runs against the real voting engine rather than stand-in data — signing with a device identity that never leaves the phone.

Authority App Reaches Design Parity, in English and Spanish

June 1, 2026

Every screen in the Authority app now matches its design, including several built from scratch: creating elections and ballots, proposing revisions to an existing election, and inviting keyholders. The whole app is available in English and Spanish, with an in-app language switch that remembers your choice. These screens run on sample data while the voting engine is wired in behind them.

VoteTorrent Runs on the Sereus Fabric

May 29, 2026

Optimystic and Quereus have been assembled into Sereus, a general-purpose fabric for applications whose data lives on participants' own devices instead of a central server — and VoteTorrent now runs on it. Each VoteTorrent network is a "strand": an invitation-only shared database, distributed across the phones and machines of the people taking part.

The Election Rulebook Becomes Code

November 5, 2025

The rules governing an election are now written directly into the data model: how networks, authorities and officers relate to one another, how invitations are issued and accepted, and how many signatures an action requires before it takes effect. Threshold signing means no single official can act alone — signing authority is split among keyholders, building on the Vinz distributed threshold key library. The database checks these rules itself, so an invalid record cannot be written in the first place.
