## Decisions Made

- **Inline lookup (not helper):** CONTEXT.md locked this — these are one-off raw-SQL seeds, not a repeated pattern worth a fixture API. Two helpers already do this for Election/Ballot scopes (`seedElectionSigning`, `seedBallot`), so the inline copies stay narrowly scoped.
- **`ctx.user?.id ?? 'user-1'` fallback in network.spec.ts:** matched the surrounding unskipped tests' style (they use the same fallback). The fallback never triggers because `NetworksEngine.createContext` always populates `ctx.user`, but the optional-chaining keeps TypeScript happy without unsafe assertions.
- **`nowCanonicalDatetime()` instead of `Date.now()` for `now` context:** the canonical-datetime contract (Phase 12.2) requires canonical-string at the schema boundary. Even though `now` is only used for `IsXxxValid` checks here, using the same canonical form across all bindings prevents quereus type-coercion edge cases.
