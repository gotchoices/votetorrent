Export this function.

**3. `seedElectionSigning(ctx, authorityId, electionInit, user, tid): Promise<{ nonce: string }>`** (Layer-2.5 primitive, per D-04/D-05)
This is the critical helper that seeds the `AdminSigning` + `AdminSignature` rows needed by `Election.InsertValid`. Steps:

a. Generate nonce via `crypto.randomUUID()`
b. Query `CurrentAdmin` for `EffectiveAt`: `select EffectiveAt from CurrentAdmin where AuthorityId = :authorityId`
c. Build the signature from user: use `makeTestSignature(user)`
d. Insert `AdminSigning` with election-specific Digest. The SQL uses the DB's registered `Digest()` function (not JS-side hash). The scope is `'mel'`. The Digest formula must match `Election.InsertValid`: `Digest(:tid, :id, :authorityId, :title, :date, :revisionDeadline, :ballotDeadline, :type)`. Convert date fields using `Temporal.Instant.fromEpochMilliseconds(...).toString()` to match what `createElection()` will bind. The `tid` parameter must be passed as a string (`String(tid)`) since `context.Tid` in the schema is bound via string interpolation. Context bindings: `with context now = :now, IsSignatureValid = true, IsSignerKeyValid = true`.
e. Call `new SigningEngine(ctx).sign(nonce, sig)` to insert `OfficerSignature` and trigger `AdminSignature` (threshold=1 for primary authority).
f. Return `{ nonce }`.

Import `Temporal` from `temporal-polyfill` for the date conversion.

**4. Rewrite `addTestElection(auth: TestAuthorityContext): Promise<TestElectionContext>`** (Layer-3 replacement)
Remove the try/catch swallow pattern. New implementation:
a. Create `electionsEngine = new ElectionsEngine(auth.ctx)`
b. Build election init via `makeElectionInit({ authorityId: auth.authority.id })`
c. Call `peekNextElectionTid()` to get the Tid that the next `createElection()` call will use
d. Call `seedElectionSigning(auth.ctx, auth.authority.id, init, auth.user, tid)` to get `{ nonce }`
e. Call `electionsEngine.createElection(init, { signingNonce: nonce })`
f. Call `electionsEngine.openElection(init.election.id)` to get the `electionEngine`
g. Return `{ ...auth, electionsEngine, electionEngine }` -- never null for `electionEngine`

Update the `TestElectionContext` interface: change `electionEngine: IElectionEngine | null` to `electionEngine: IElectionEngine` (no longer nullable since the seeding pipeline guarantees success).
