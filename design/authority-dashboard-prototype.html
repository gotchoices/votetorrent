Authority Dashboard

Prototype of apps/VoteTorrentDashboard. Tokens, class names and copy transcribed from source. Fixture data is synthetic at production length.

Two screens. main.tsx opens the live shell when this browser's registry holds a paired network and the pairing screen otherwise. A browser restored by the retired sign-in code is a legacy entry and never reaches the shell; pasting such a code is the "old sign-in code" failure. The shell's "+ Pair another network" stops the running network first; Escape on the pairing screen returns to it while it is still paired.

Scanning is hidden. QrScanner.tsx (webcam viewfinder, camera prompts, "Paste the code instead") is still in source with its copy, but the Scan QR code button and the scanner mount are commented out in Pairing.tsx for this release. Paste is the only pairing path, so the prototype draws no scanner.

Status chip. One chip in the top bar is the page's only status role. "Live" is earned by a read pass that started while connected and finished in the last 40 s; a disconnection reads as Offline only after 10 s; a change of kind is held for 1 s before it shows. At the 900 width the chip's time drops to a second line. The rail jumps straight to each state.

Change marks. A row or figure a pass changed gets a 2px primary bar and a 15% tint for 4 s, then fades over 2.5 s (static under reduced motion), plus a visually hidden word "updated". More than 25 changed rows, or any deleted row, marks the panel header instead. Marks never fire on the first catch-up or a local-copy load. The grid's one polite live region text is shown in the label above the stage.

The 900 width crosses shell.css's max-width:900px breakpoint, where .sh-body collapses from a 220px sidebar + panels to one column. .sh-layout has no padding in source, so the top bar sits flush against the window edge.

Chart / Grid. Every visible panel carries the switch in its header, but only Registrations and Keyholders change body with it; the intake time series shows in both views. A choice persists per panel under vt-dashboard-panel-view:<id>; a panel never chosen opens on Chart. Rail entries below override the stored choice without writing it.

No light theme. tokens.css declares one dark token set and no prefers-color-scheme rule, so the dashboard has no light mode to toggle.

Keyholder releases. The Keyholders panel's roster query selects no ReleasedAt, so no release count appears here because none appears in the app.
