Authority Dashboard

Prototype of apps/VoteTorrentDashboard. Tokens, class names and copy transcribed from source. Fixture data is synthetic at production length.

The 900 width crosses shell.css's max-width:900px breakpoint, where .sh-body collapses from a 220px sidebar + panels to one column.

Chart / Grid. Every visible panel carries the switch in its header, but only Registrations and Keyholders change body with it; the intake time series shows in both views. A choice persists per panel under vt-dashboard-panel-view:<id>; a panel never chosen opens on Chart. Rail entries below override the stored choice without writing it.

No light theme. tokens.css declares one dark token set and no prefers-color-scheme rule, so the dashboard has no light mode to toggle. The prototype renders identically whatever the OS asks for.

Keyholder releases. The officer roster read in web-data now carries each keyholder's published ReleasedAt, but this dashboard's Keyholders panel reads its own roster query, which does not select it. No release count appears here because none appears in the app.
